## 偏離（負責人接受）

- 不做完整備份還原與主機重開，只做局部還原（一般與加密）、版本混搭（T-20）、add-on 重啟（負責人 2026-11-23）。
- 容量與極端壓力只記錄、不擋發版（負責人 2026-11-23）；T-17 的數字照記，契約暫定值（每子程式 160 MiB、最壞 896 MiB）只是公式，未量最壞情況。
- 一般負載的 `--modes bench,cycle`（選做）沒有跑。

## 已知限制（不擋這一版）

- 經 Cloudflare 開 HA 時，面板不能儲存「瀏覽器來源檢查」設定（F2，與 Odoo 0.5.1 同一份面板）：只影響這一張卡片，預設值照常運作，從區網開 HA 可以儲存；下一版修。負責人 2026-11-24 決定先發。
- 後續（2026-11-25）：F2 在維修版修好了：面板也把 Cloudflare 這類代理改成的弱 ETag（`W/"…"`）當成同一個版本，送出時照舊送強的 `If-Match`，add-on 的比對沒有放寬；帳號清單有同樣的問題（唯讀、「全部撤銷」停用），一起修（`docs/multi-profile/unreleased-changes.md` A11）。上面寫的是這一版映像的行為，沒有改。
- 一個帳號的密碼錯，會讓同一個 add-on 其他帳號的新登入被延遲（UC-12，見上表）。DOCS 下一版補寫；清除方法：`occ security:bruteforce:reset <add-on 的位址>` 或 Nextcloud 管理頁。
