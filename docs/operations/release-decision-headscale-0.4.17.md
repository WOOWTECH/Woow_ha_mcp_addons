# woow_mcp_headscale 0.4.17 image decision

Status: **exact-source image built, tested, scanned, published, and anonymously verified**. Stable Release, Store synchronization, and both production HAOS upgrades remain acceptance gates.

0.4.17 publishes the already-reviewed multi-address DNS fallback in the first Headscale image after 0.4.16: every validated address is tried in order within one bounded connection deadline, so an unreachable first DNS answer no longer hides a reachable later answer. The 0.4.16 Headscale secret-URL Origin policy remains unchanged: native clients without Origin and the exact `https://claude.ai` connector Origin are allowed; untrusted, malformed, or repeated Origin headers receive HTTP 403. The Bearer `/mcp` endpoint, the 29 native Headscale API operations, and the other products remain unchanged.

Reviewed source commit: `a41b7b1ab50305804fbfe692c25356b9658cdfd2`. Its complete reachable history was transferred as a SHA256-verified Git bundle, checked with `git fsck`, materialized at that exact detached commit, and required to be clean before build. The accepted one-use amd64 KubeVirt builder used Docker 28.5.2, an isolated 60 GiB Longhorn volume, no service-account token, empty namespace RBAC, default-deny networking, and public HTTP(S)-only egress. The private source bundle, scanner cache, evidence, and Docker credential directory were restricted to the release operator. The Docker credential directory was removed immediately after logout.

Two earlier builder attempts were rejected before publication: the first inherited the private evidence umask into the Docker context and made copied runtime files unreadable by UID 10001; the second exhausted the VM's small root `/tmp` while Syft wrote its SBOM. The accepted round materialized only the public source worktree with normal CI mode semantics and placed all scanner temporary data on the isolated build volume. The exact image ID remained stable after that correction. No failed round was tagged or pushed.

The exact tested image ID is `sha256:0929a65e568f7e2888561e87821809957ef16a00a1da60b3e6b21f4bf59d6daf`. Container/mock acceptance passed on that ID: runtime labels, isolation, bootstrap, UID, protocol, authentication, policy, backend outage, persistence, and shutdown. Source/history/all-layer secret scans, Syft and SPDX all-layer SBOM, Grype vulnerability, and license policies passed on the same image. The SBOM contains 193 packages and the Grype report contains 252 findings; policy pass does not mean zero findings. A second verification bound the current local image to the candidate evidence before publication. See the [subject](../provenance/headscale-0.4.17-subject.json), [scan summary](../provenance/headscale-0.4.17-scan-summary.json), and [unsigned candidate provenance](../provenance/headscale-0.4.17-provenance.json).
