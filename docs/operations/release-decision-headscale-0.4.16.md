# woow_mcp_headscale 0.4.16 image decision

Status: **exact-source image built, tested, scanned, published, and anonymously verified**. Stable Release, Store synchronization, and both production HAOS upgrades remain acceptance gates.

0.4.16 publishes the Headscale MCP secret URL Origin restriction: native clients without Origin and the exact `https://claude.ai` connector Origin are allowed; untrusted, malformed, or repeated Origin headers receive HTTP 403 after URL-token validation. Bearer `/mcp`, all other products, and the 29 native Headscale API operations are unchanged. Only Headscale advances to 0.4.16. The 0.4.15 image was an unpublished candidate for Store purposes: it was pushed but its embedded runtime ledger predated the final reviewed correction, so it was never promoted to Stable Release or production.

Reviewed source commit: `efcc63ed12364c8a63467841f8c80d4ff3339221`. The complete reachable history was transferred in a SHA256-verified Git bundle, checked out at that exact commit, checked with `git fsck`, and required to be clean before build. The one-use amd64 builder used Docker 28.5.2 image index `sha256:2a232a42256f70d78e3cc5d2b5d6b3276710a0de0596c145f627ecfae90282ac`, an isolated Longhorn volume, no service-account token, public-only HTTP(S) egress, and an internal Docker Unix socket. Its namespace is `hsbuild-0416-778536` until post-publication cleanup.

The exact tested image ID is `sha256:9b12c1e1e74e824954539914e5f506e5c618e4c454060f3f114c928ff7a29b2b`.
