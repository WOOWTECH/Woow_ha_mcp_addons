# Headscale child 來源與工具審查

本地 Headscale child 的來源固定為 `WOOWTECH/woow-mcp-server@d7c78aaeff001f5fcf87f69ecd3db290396a5906`，`apps/headscale/headscale_mcp_server/`。來源 `apps/headscale/pyproject.toml` 宣告來源專案 `woow-headscale-mcp-server` 版本 `0.1.1`、授權 `MIT`（該檔 SHA256：`444ccec92e9f41e114e49a30cc4bd0f8c3009d331b11f68fa9a729bc1f666c62`）；本 repo 的 `apps/headscale/pyproject.toml` 是獨立 child 包裝，版本欄為 `0.0.0`，不能把來源專案版號當成本地 child 版號。來源沒有獨立 LICENSE 檔；vendored `apps/headscale/vendor/LICENSE` 是同一來源倉庫使用的 WOOWTECH MIT 全文。11 個 Python 檔及 LICENSE 的本地、來源雜湊與逐檔差異見 [`runtime-sources.json`](runtime-sources.json)；vendored child 的複製說明見 `apps/headscale/vendor/PROVENANCE.md`。

這個 child 的 native API 合約對應 [Headscale v0.29.4](https://github.com/juanfont/headscale/releases/tag/v0.29.4)，固定參考 `juanfont/headscale@8106636c7f8d0cf8c9d4fb0beae94415069b768b` 的 [v1 proto](https://github.com/juanfont/headscale/blob/8106636c7f8d0cf8c9d4fb0beae94415069b768b/proto/headscale/v1/headscale.proto)。Headscale 上游程式的 [BSD-3-Clause 授權](https://github.com/juanfont/headscale/blob/8106636c7f8d0cf8c9d4fb0beae94415069b768b/LICENSE) 與 WOOWTECH child 的 MIT 授權分開；這裡 vendored 的是 WOOWTECH Python child，不是 Headscale 上游 Go 程式。

`scripts/tool_inventory.py` 只解析 vendored `registry.py` 的 `_GROUPS`／`_FIXED`、`native.py` 的 `NATIVE_OPERATIONS` 與 `server.py` 的 `add_tool` 註冊路徑 AST，不執行 child 原始碼。審查結果為 11 支工具、29 個唯一 native operations；`headscale_policy.diff` 是 child 衍生操作，沒有對應單一 native ID。工具與操作清單、效果分類及來源 SHA256 見 [`tool-surface.json`](../tool-surface.json)；逐工具准入理由見 [`tool-review.json`](../tool-review.json)。未知或變更的名稱、動態註冊路徑、native 綁定與效果分類須先審查，不能靠重新生成文件自動放行。

本地 HA 差異主要是每次呼叫讀取已儲存的 schema-4 policy，將目的地與 HTTP 傳輸限制在 HA 的位址政策，隱藏憑證，以及僅註冊這 11 支工具。功能差異涉及 `client.py`、`http_policy.py`、`operation_policy.py`、`policy.py`、`registry.py`、`server.py`。其中八個 vendored Python 檔另修剪了結尾多餘空行；因此現在十個 Python 檔有本地 SHA256，僅 `log_redaction.py` 與來源逐位元相同。共用 core/UI 的九個更新檔與 Headscale 子程序的七個 HTTPX/httpcore guard 雜湊見 [`runtime-patches.json`](runtime-patches.json)。Headscale 只接受新安裝狀態，沒有 0.1.x 升級路徑；原有產品的 `0.2.0` 工具開放決策不表示 Headscale child 採用該版號。
